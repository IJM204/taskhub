# Arborescence du projet TaskHub

## 1. manage.py
Permet d'exécuter les commandes Django.
Il sert à lancer le serveur, créer des applications et effectuer les migrations.

## 2. settings.py
Contient la configuration générale du projet.
Il définit les applications, la base de données et les paramètres de sécurité.

## 3. urls.py
Définit les routes du projet Django.
Il associe les adresses URL aux vues correspondantes.

## 4. wsgi.py
Permet de déployer Django avec un serveur compatible WSGI.
Il sert principalement aux applications web synchrones.

## 5. asgi.py
Permet de déployer Django avec un serveur compatible ASGI.
Il prend notamment en charge les fonctionnalités asynchrones.
